# Product screenshots

[Product page](../../../README.md) · [Documentation index](../../README.md)

Captured on Windows on 24 October 2026 from the actual Tkinter application at [source revision d745e8f](https://github.com/haribo841/kolejka-transkrypcji/tree/d745e8fe6b2bf76470660f1394c09cd35d2e5151). Both JPEG files are unmodified window captures.

- **[local-queue.jpg](local-queue.jpg):** an isolated demonstration queue with ten illustrative recordings, three marked complete and seven waiting. No worker is running.
- **[transcript-tools.jpg](transcript-tools.jpg):** the actual before/after preview for removing speaker labels while keeping timestamps and text. The demonstration exports were generated by `batch.exporter.export` from scripted segments. The [TXT](../../examples/demo-transcript.txt) and [SRT](../../examples/demo-transcript.srt) contain the same illustrative dialogue.

The example text is demonstration data, not a measurement of speech-recognition accuracy. Screenshot preparation did not start model inference, downloads or the production queue. The demo window was closed after capture.
